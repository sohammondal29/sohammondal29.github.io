# Soham Mondal — Portfolio

A single-file, responsive GitHub Pages portfolio built from the provided resume.

## Deploy on GitHub Pages
1. Create a **public** repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload `index.html` to the repository root and commit.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Visit `https://YOUR_GITHUB_USERNAME.github.io/`.

## Before publishing
- Replace generic LeetCode, Codeforces and LinkedIn URLs with your actual profile URLs.
- Update each project GitHub link from your profile URL to the exact repository.
- Add a real project/demo URL if you want each project to have a live demo.
- Review the displayed contact information before publishing publicly.

The site uses Google Fonts (Space Grotesk, Syne, DM Mono); a connection is required to load those fonts. All layout, styling and interactions are contained in `index.html`.
